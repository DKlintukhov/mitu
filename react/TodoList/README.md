# Запуск проекта

## 1. Установите NodeJS
Скачайте и установите NodeJS с официального сайта: https://nodejs.org/en/download.

## 2. Склонируйте репозиторий
```
https://github.com/DKlintukhov/mitu.git
```

## 3. Перейдите в директорию проекта
```
cd mitu/react/TodoList
```

## 4. Установка зависимостей для фронтенда
```
npm install
```

## 5 Установка и запуск бэкенда
### В новом терминале перейдите в папку backend
```
cd backend
```
### Установите зависимости и запустите сервер
```
npm install
node server.js
```

## 6 Запуск фронтенда
```
npm run dev
```
### Фронтенд будет доступен по адресу:
```
http://localhost:5173
```

## 7. Запуск тестов
```
npm test
```
