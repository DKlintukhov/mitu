## 1. Установите NodeJS
Скачайте и установите NodeJS с официального сайта: https://nodejs.org/en/download.

## 2. Склонируйте репозиторий
```
https://github.com/DKlintukhov/mitu.git
```

## 3. Перейдите в директорию проекта
```
cd mitu/tests
```

## 4. Установите зависимости
```
npm install
```

## 7. Запуск тестов
```
npm test
```
